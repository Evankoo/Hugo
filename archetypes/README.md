# 网站 Markdown 写作规范

这套规则让 Markdown 只表达内容语义，字号、颜色和间距全部由网站统一处理。

## 标题

- Frontmatter 的 `title` 是文章唯一的 H1，正文不要写 `# 标题`。
- H2（`##`）是主要章节，H3（`###`）是章节内的次级主题。
- H4（`####`）只用于短小的判断、标签或局部说明。
- 新文章不使用 H5、H6，也不要跳过标题层级。
- 标题不手工编号，不用加粗段落代替标题。

## 正文与强调

- 每段只表达一个相对完整的意思，段落之间保留一个空行。
- `**加粗**` 只强调关键词或结论，不整段加粗。
- `*斜体*` 用于语气或术语，不承担标题层级。
- 分隔线 `---` 只用于明显的语义转折，避免连续使用。

## 引用、列表与提示

- `>` 只用于真实引文，不用于普通强调。
- 有顺序的操作用有序列表；并列信息用无序列表。
- 提示块只有三种：`key-point`、`note`、`warning`。

```md
{{< callout type="key-point" >}}
真正影响理解或行动的核心结论。
{{< /callout >}}
```

## 图片

所有图片都必须填写准确的替代文字。图片需要图注时，把图注写在 Markdown 图片标题中：

```md
![关系循环示意图](/images/cycle.png "图 1｜关系循环示意")
```

没有标题时只显示图片，不生成空图注。图片不手工添加边框、阴影或宽度样式。

## 表格、代码与脚注

- 表格只用于确实需要纵横比较的数据；普通内容不要为了对齐而放进表格。
- 短字段或命令使用行内代码，多行内容使用围栏代码块。
- 脚注只放来源和必要补充，不在脚注中继续主要论证。

```md
正文中的来源说明。[^1]

[^1]: 作者，《书名》，出版社，年份，第 X 页。
```

## 可用模板

- `long-form.md`：长文／随笔。
- `reading-note.md`：读书笔记。
- `method-guide.md`：方法／指南。

旧文章保持兼容，不批量改写；文章被重新编辑时，再按本规范逐篇调整。
