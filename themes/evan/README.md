# Evan theme

This is the local base theme for evan-manual.com. It is a deliberately reduced
derivative of [Anatole 1.18.0](https://github.com/lxndrblz/anatole/releases/tag/v1.18.0).

Only runtime templates, SCSS, JavaScript, and the active translations are kept.
Site-specific overrides live at the repository root. Anatole's MIT license is
retained in `LICENSE`.
